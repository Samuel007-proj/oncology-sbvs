# Project overview — Multi-Target Oncology SBVS

**Title:** Discovery of Novel Small-Molecule Chemotypes Against KRAS G12D • PRMT5 (MTA-cooperative) • TEAD • SMARCA2  

**Author:** Samuel Damilare Oyelami  
**Date:** October 2026  

## Executive summary

This campaign uses structure-based virtual screening (SBVS) to generate a diversified portfolio of novel, target-specific small-molecule chemotypes against four high-value oncology targets. Expected deliverable: 40–80 prioritised hit candidates (~10–20 per target) with favourable predicted ADME and clear IP space.

## Computational workflow

1. Structure selection and preparation  
2. Seed chemotype definition and library expansion (ChEMBL + PubChem + RDKit)  
3. Validation of docking protocol (crystal ligand RMSD after minimisation)  
4. Virtual screening, filtering, and prioritisation *(ongoing)*  

See `scripts/` and `notebooks/` for implementation details.
